<h2>TheBridge</h2>
<p><b>A classic Bridge minigame plugin: fight across bridges over the void and score in the enemy goal.</b></p>

<p>Create as many 1v1 or 2v2 arenas as you like. Everything is set up with in-game commands and <code>config.yml</code>. No coding needed.</p>

<h3>Features</h3>
<ul>
<li>1v1 and 2v2 arenas, unlimited arenas</li>
<li>Setup commands with clear error messages</li>
<li>Automatic goal detection, respawn delay, void deaths, kill credit</li>
<li>Custom starting equipment and buildable blocks</li>
<li>Automatic arena reset after every match (only changed blocks, restored in small batches)</li>
<li>Player inventory, game mode, health and position restored after the match, also after a crash</li>
<li>SQLite statistics (wins, losses, goals, kills, deaths, win streak)</li>
<li>Titles, action bar, sounds, optional console-command rewards, editable messages</li>
</ul>

<h3>Requirements</h3>
<ul>
<li>Java 21</li>
<li>Paper 1.21+ or a Paper fork (Folia is not supported)</li>
</ul>

<h3>Quick start</h3>
<ol>
<li>Put the jar into the plugins folder and restart.</li>
<li><code>/thebridge create &lt;arena&gt;</code>, then set lobby, spawns, goals and bounds (<code>/thebridge help</code>).</li>
<li><code>/thebridge enable &lt;arena&gt;</code>. Players join with <code>/thebridge join &lt;arena&gt;</code>.</li>
</ol>

<h3>Permissions</h3>
<p>thebridge.join, thebridge.leave, thebridge.stats (everyone) / thebridge.admin, thebridge.bypass (OP)</p>
